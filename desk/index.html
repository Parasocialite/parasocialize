The queue

What the machine turned down, and why

Kept on purpose. A classifier that only shows you what it likes is a classifier you cannot audit, and the entire claim of this site is that the line is deliberate.

Signing off

To publish a draft: edit data/queue.json — set "state":"signed", fill in section, law and shelf if the model left them null — move the object into cards in data/shop.json with a slug, filed and a state, then run python tools/build_cards.py. The hourly job picks the commit up.

Give it a real sources[0].url. A card with an unresolved link is rendered with a treat with suspicion note on purpose, and that is a thing to fix rather than leave.

Going away? Set PARASOCIALIZE_BUDGET=0. The sweeper keeps running and the queue keeps filling, and nothing reaches anybody until you are back. A backlog beats a shelf you did not read.
